# 舞蹈课时统计分析系统 PRD

## 模块目标

本系统为舞蹈培训机构提供课时管理数字化方案，覆盖主数据配置、课时记录、数据分析三个核心模块，帮助业务人员快速完成课时登记、统计查询与决策分析。

**原型用途**：面向业务（舞蹈课时记录用户）与产品进行评审，验证主数据配置能力、课时记录流程、数据分析流程的业务方案是否成立。

## 使用对象

- **课时记录员**：负责日常课时登记、调整、核销操作。
- **教学主管**：查看课时统计、教师课时分析，进行排课决策。
- **产品经理**：评审原型方案，确认功能范围与业务规则。

## 页面范围

| 菜单 | 路由 | 核心任务 |
| --- | --- | --- |
| 主数据配置 | `/master-data` | 舞种、教师、学员、教室/场地、舞室的增删改查 |
| 课时记录 | `/class-hour-record` | 课时登记、核销、调整、批量导入 |
| 数据分析 | `/analysis` | 课时统计、教师课时分析、学员课时分析 |

## 业务目标

1. 将舞蹈机构的教师、学员、舞种、教室等主数据统一录入，消除分散记录。
2. 提供标准化的课时登记流程，支持单次登记与批量导入，记录核销状态。
3. 提供多维度的课时数据分析，支持按教师、学员、舞种、时间段进行统计。

## 输入与操作

### 主数据配置页（`/master-data`）

| 区域 | 用户操作 | 系统响应 |
| --- | --- | --- |
| 舞种管理 | 新增舞种（名称、分类、课时单价）、编辑、删除 | 保存后列表刷新；删除前需确认 |
| 教师管理 | 新增教师（姓名、联系方式、擅长舞种、状态）、编辑、禁用 | 保存后列表刷新；禁用后不可排课 |
| 学员管理 | 新增学员（姓名、联系方式、绑定舞种、累计课时、状态）、编辑 | 保存后列表刷新 |
| 教室管理 | 新增教室（编号、容量、位置、状态）、编辑、删除 | 删除前需确认 |
| 顶部搜索 | 输入关键词、舞种筛选、状态筛选、点击查询 | 按条件过滤列表 |

### 课时记录页（`/class-hour-record`）

| 区域 | 用户操作 | 系统响应 |
| --- | --- | --- |
| 课时登记 | 点击"登记课时"，填写教师、学员、舞种、日期、课时数、状态，提交 | 保存成功提示，列表刷新 |
| 课时核销 | 对"待核销"记录点击核销，确认后状态变为"已核销" | 核销不可逆，需二次确认 |
| 课时调整 | 对已登记记录点击调整，修改课时数并填写调整原因 | 修改后列表刷新，保留调整记录 |
| 批量导入 | 点击"批量导入"，上传 Excel 文件 | 解析成功后显示预览，确认后批量写入 |
| 顶部搜索 | 按日期范围、教师、学员、舞种、状态筛选 | 按条件过滤列表 |

### 数据分析页（`/analysis`）

| 区域 | 用户操作 | 系统响应 |
| --- | --- | --- |
| 统计概览 | 查看当月课时总数、已核销课时、待核销课时、各舞种课时分布 | 数据从课时记录聚合计算 |
| 教师课时分析 | 按教师维度查看课时量、核销率、占比 | 支持切换时间范围 |
| 学员课时分析 | 按学员维度查看累计课时、最近上课时间、剩余课时 | 支持导出明细 |
| 舞种课时分布 | 查看各舞种课时量柱状图 | 支持切换月份 |
| 导出 | 点击"导出统计" | 生成 Excel 文件下载 |

## 输出与状态

**主数据状态**：

| 状态 | 含义 |
| --- | --- |
| 启用 | 数据正常可用 |
| 禁用 | 数据已停用，不可新建关联 |

**课时记录状态**：

| 状态 | 含义 |
| --- | --- |
| 待核销 | 已登记，待确认消耗 |
| 已核销 | 课时已确认消耗 |
| 已调整 | 课时数已被修改 |
| 已作废 | 记录已删除（逻辑删除） |

## 业务规则

1. 课时登记时，教师与学员必须从已启用的主数据中选择。
2. 同一教师在同一日期同一时段不可重复登记。
3. 课时数为正整数，单次最大不超过 4 课时。
4. 核销操作不可逆，核销后如需修改须通过"课时调整"流程。
5. 禁用教师后，历史课时记录保留，但不可再为其新增登记。
6. 批量导入失败时，显示错误行号及原因，不影响成功行。
7. 数据分析数据来源于课时记录表，统计时排除"已作废"记录。

## 异常与边界

- 批量导入文件格式不符时，提示文件格式要求并列出成功/失败数量。
- 课时调整超过原值 2 课时以上需填写调整原因。
- 数据删除采用逻辑删除，不物理删除记录。
- 教师或学员数据被引用时不允许物理删除，只能禁用。

## 验收标准

- `/home` 可访问，侧边栏包含全部三个业务菜单入口。
- 主数据配置页支持舞种、教师、学员、教室四个维度的增删改查。
- 课时记录页支持单次登记、核销确认、课时调整、批量导入。
- 数据分析页可展示课时概览、教师分析、学员分析、舞种分布。
- 顶部"文档"入口可打开当前页面对应 PRD。
- `npm run build` 通过无报错。
