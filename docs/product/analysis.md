# 数据分析 PRD

## 模块目标

数据分析模块基于课时记录数据，提供多维度课时统计与可视化展示，帮助教学主管了解课时消耗情况、教师工作量分布、学员上课频率，支持管理决策。

## 使用对象

- **教学主管**：查看课时统计、教师课时分析，进行排课与资源调配决策。
- **产品经理**：评审分析维度和数据展示方案。

## 页面结构

页面采用 `PageHeader` + 统计概览卡片区 + 分析 Tabs 区的布局。

统计概览区：四个 `MetricCard` 展示当月核心指标（总课时、已核销、待核销、平均课时单价）。
分析 Tabs：三个 Tab 页（教师课时分析 / 学员课时分析 / 舞种课时分布），每 Tab 含独立筛选与数据表。
顶部工具栏：全局时间范围筛选、舞种筛选、导出统计按钮。

## 输入与操作

### 全局筛选

| 筛选项 | 类型 | 说明 |
| --- | --- | --- |
| 时间范围 | DatePicker.RangePicker | 默认当月，最大跨度12个月 |
| 舞种 | Select（多选） | 空=全部，支持多选 |
| 导出 | Button | 导出当前筛选条件下的 Excel 报表 |

### Tab 1：教师课时分析

| 字段 | 说明 |
| --- | --- |
| 教师姓名 | 教师标识 |
| 总课时数 | 统计期内课时总数 |
| 已核销课时 | 已核销数量 |
| 待核销课时 | 待核销数量 |
| 核销率 | 已核销/总课时，百分比 |
| 平均课时单价 | 按舞种加权平均 |
| 最近更新 | 最后一条记录时间 |

操作：点击教师行展开详情（Drawer），显示该教师课时明细列表。

### Tab 2：学员课时分析

| 字段 | 说明 |
| --- | --- |
| 学员姓名 | 学员标识 |
| 绑定舞种 | 主修舞种 |
| 累计课时 | 统计期内上课总数 |
| 最近上课时间 | 最后一次上课日期 |
| 剩余课时 | 待核销课时数 |
| 上课频次 | 每周平均课时（可切换显示） |

操作：点击学员行展开详情（Drawer），显示该学员课时明细列表。

### Tab 3：舞种课时分布

以柱状图形式展示各舞种课时量，支持切换时间维度（月/季度/年）。
表格视图：舞种名称、课时数、占比、趋势（较上月增减）。

## 输出与状态

### 统计概览卡片

| 卡片 | 数据源 | 说明 |
| --- | --- | --- |
| 当月总课时 | 课时记录已核销+待核销 | 统计期内所有有效课时 |
| 已核销课时 | 状态=已核销的记录 | 已完成消耗的课时 |
| 待核销课时 | 状态=待核销的记录 | 待确认消耗的课时 |
| 平均课时单价 | 舞种单价×课时数加权 | 反映收入水平参考值 |

### 数据更新说明

- 统计数据从课时记录表实时聚合，依赖课时记录的完整性。
- 已作废记录不参与统计计算。
- 核销后统计数据自动更新（次日凌晨定时任务或实时刷新）。

## 业务规则

1. 统计概览数据默认展示当月，可切换时间范围。
2. 教师/学员分析默认按总课时降序排列，支持点击列头排序。
3. 舞种课时分布默认按课时量降序，柱状图与表格数据同步。
4. 导出功能生成 Excel，含当前筛选条件与所有 Tab 数据。
5. 数据量超过 1000 条时分页加载，每页 20 条。
6. 分析数据仅展示已启用的教师、学员、舞种对应的记录。

## 异常与边界

- 无符合条件的记录时，各 Tab 显示 `Empty` 组件。
- 统计概览卡片无数据时显示"0"，不显示错误。
- 导出失败时显示 `notification.error` 提示，不中断页面。
- 时间范围跨年时，舞种分布按年汇总展示。

## 验收标准

- 统计概览区四个卡片数据与课时记录一致。
- 三个 Tab 均可切换，各含筛选与排序能力。
- 教师/学员行点击可展开详情 Drawer。
- 舞种分布支持柱状图与表格双视图。
- 导出功能可生成文件。
- 顶部"文档"入口可打开此 PRD。
