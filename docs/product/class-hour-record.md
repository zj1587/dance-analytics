# 课时记录 PRD

## 模块目标

课时记录模块是舞蹈课时统计分析系统的核心业务模块，支持课时登记、核销、调整、批量导入四大操作，为数据分析提供可靠的数据源。

## 使用对象

- **课时记录员**：日常课时登记、核销、调整操作。
- **教学主管**：审核批量导入、查看异常记录。
- **产品经理**：评审课时记录流程与规则。

## 页面结构

页面采用 `PageHeader` + 筛选区 + 工具栏 + 主表格的布局。

顶部筛选区：日期范围（DatePicker.RangePicker）、教师下拉、学员下拉、舞种下拉、状态标签筛选、查询/重置按钮。
工具栏：登记课时（主要操作）、批量导入、导出。
主表格：课时记录列表，含操作列（核销、调整、作废）。
底部：分页控件。

## 输入与操作

### 课时登记（Drawer）

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| 教师 | Select | 是 | 从启用状态的教师列表选取 |
| 学员 | Select | 是 | 从在读学员列表选取 |
| 舞种 | Select | 是 | 从启用状态的舞种列表选取 |
| 上课日期 | DatePicker | 是 | 必填，不可选未来日期 |
| 上课时段 | Select | 是 | 如"09:00-10:30"、"14:00-15:30" |
| 课时数 | InputNumber | 是 | 正整数，1-4，默认1 |
| 备注 | Input.TextArea | 否 | 可选补充说明 |

提交后：显示成功提示，Drawer 关闭，列表刷新，新增记录状态为"待核销"。

### 课时核销

- 仅对"待核销"状态记录可用。
- 点击核销后弹出 `Popconfirm` 确认框："确认核销此条课时记录？核销后不可撤销。"
- 确认后状态变为"已核销"，学员累计课时自动+1，不可再修改。

### 课时调整（Drawer）

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| 新课时数 | InputNumber | 是 | 正整数，1-4 |
| 调整原因 | Input.TextArea | 条件必填 | 调整幅度超过2课时时必填 |

提交后：状态变为"已调整"，学员累计课时按差额增减，保留调整记录。

### 批量导入

- 点击"批量导入"弹出文件上传区，支持 `.xlsx` / `.xls` 格式。
- 上传后先解析预览，显示成功行数与失败行数，失败行标注原因。
- 用户确认后批量写入，失败行不写入。
- 导入模板字段：教师、学员、舞种、上课日期、上课时段、课时数、备注。

## 输出与状态

### 列表展示字段

| 字段 | 说明 |
| --- | --- |
| 记录编号 | 自动生成，格式 DH + 日期 + 序号 |
| 上课日期 | YYYY-MM-DD |
| 上课时段 | 如 09:00-10:30 |
| 教师 | 教师姓名 |
| 学员 | 学员姓名 |
| 舞种 | 舞种名称 |
| 课时数 | 数字，右对齐 |
| 状态 | 待核销（金色）/ 已核销（绿色）/ 已调整（蓝色）/ 已作废（灰色） |
| 登记时间 | 记录创建时间 |
| 操作 | 核销/调整/作废（按状态显示可用操作） |

### 状态流转

```
待核销 → 已核销（核销，不可逆）
待核销 → 已调整（调整，原记录保留）
待核销/已调整 → 已作废（作废，逻辑删除）
```

## 业务规则

1. 同一教师在同一日期同一时段不可重复登记，重复时提交失败并提示冲突。
2. 课时数限制 1-4 课时，超出范围校验失败。
3. 核销操作不可逆，需二次确认。
4. 课时调整超过原值 ±2 课时时，调整原因为必填项。
5. 已作废记录不参与数据分析统计。
6. 批量导入时，教师/学员/舞种不存在或已禁用时，该行标记为失败。
7. 课时数修改后，学员累计课时同步调整差额。

## 异常与边界

- 无课时记录时，表格区域显示 `Empty` 组件，提示"暂无课时记录"。
- 批量导入全部失败时，显示失败原因汇总，不写入任何数据。
- 网络异常时，操作失败显示 `message.error`，不改变本地数据。
- 日期范围筛选最大跨度为 12 个月。

## 验收标准

- 课时登记 Drawer 字段完整，校验规则生效。
- 核销按钮仅对待核销记录显示，点击后确认弹窗弹出。
- 调整操作支持，调整幅度超2课时时原因必填。
- 批量导入支持预览与确认写入。
- 状态标签颜色符合规范：待核销金色、已核销绿色、已调整蓝色、已作废灰色。
- 顶部"文档"入口可打开此 PRD。
