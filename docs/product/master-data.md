# 主数据配置 PRD

## 模块目标

主数据配置模块用于统一管理舞蹈培训机构的基础数据，包括舞种、教师、学员、教室/场地四类实体。所有业务操作（课时登记、统计分析）均依赖这些主数据，确保数据一致性和可追溯性。

## 使用对象

- **课时记录员**：需要准确选择教师、学员、舞种进行课时登记。
- **教学主管**：维护教师信息、教室资源，分配排课。
- **管理员**：配置舞种字典、教室资源。

## 页面结构

页面采用 `PageHeader` + 主工作区布局，主工作区分为四个管理板块，每板块独立维护。

顶部筛选区：关键词搜索框、舞种筛选下拉、状态筛选下拉、查询/重置按钮。
主工作区：四个 `SectionPanel` 分别管理舞种、教师、学员、教室，各含独立表格与操作区。

## 输入与操作

### 舞种管理

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| 舞种名称 | Input | 是 | 如"芭蕾"、"街舞"、"中国舞" |

## 输出与状态

### 列表展示字段

| 板块 | 列表字段 |
| --- | --- |
| 舞种 | 舞种名称、分类、课时单价、状态、更新时间 |
| 教师 | 教师姓名、手机号、擅长舞种、入职日期、状态、更新时间 |
| 学员 | 学员姓名、手机号、绑定舞种、累计课时、状态、更新时间 |
| 教室 | 教室编号、教室名称、容量、位置、状态、更新时间 |

### 状态定义

- **舞种/教室**：启用（绿色）、禁用（灰色）。
- **教师**：启用（绿色）、禁用（橙色，不可排课）。
- **学员**：在读（绿色）、休学（金色）、毕业（灰色）。

## 业务规则

1. 舞种名称不可重复。
2. 教师手机号全局唯一，重复时提示已存在。
3. 禁用舞种后，已有课时记录保留，但不可在新登记中选用。
4. 禁用教师后，不可再为其新增课时登记，历史记录保留。
5. 删除舞种/教室前，检查是否存在关联课时记录，有关联则禁止删除，提示需先处理关联数据。
6. 教室编号全局唯一。
7. 学员累计课时为只读展示字段，由课时记录自动累计；手动修正需填写修正原因。

## 异常与边界

- 搜索无结果时，表格区域显示 `Empty` 组件，提示"暂无舞种数据"等具体文案。
- 表单提交失败时，`message.error` 提示失败原因。
- 新增/编辑表单校验不通过时，对应字段显示红色错误提示。

## 验收标准

- 四个管理板块均可独立打开、增删改查。
- 删除操作需二次确认弹窗。
- 禁用/启用切换立即生效，影响课时登记时的可选范围。
- 重复数据提交时给出明确错误提示。
- 顶部"文档"入口可打开此 PRD。
